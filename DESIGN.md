# AI DUEL — дуэль ИИ-хакеров

Игра, где Николай и его брат обучают по ИИ-персонажу (мозг — Haiku 5.5), и эти
персонажи взламывают серверы друг друга на арене-терминале. Всё происходит
**внутри игры** — никаких реальных компьютеров, аккаунтов и подписок. Побеждает
не тот, у кого лучше интернет, а тот, кто лучше обучил своего персонажа.

## Решения (из грилла)

- **Жанр:** два «кода»/две машины, одна ломает другую.
- **Механика взлома:** фейковые серверы в стиле Hacknet (порты, файервол, флаг).
- **Визуал:** хакерский терминал — два терминала по бокам, карта сети по центру, чат ИИ снизу.
- **Подготовка:** игрок сам расставляет свою защиту блоками (как в Scratch), объясняет своей модели стратегию.
- **Ходы:** фиксированный набор понятных команд + ИИ общаются между собой (блеф, уговоры).
- **Обучение между боями:** системный промпт + книга приёмов (файл), игрок правит сам.
- **Режим боя:** пошагово вживую, оба онлайн, сервер ждёт ход от обоих и считает раунд.
- **Инфра:** мозг — `claude -p --model haiku` по подписке Claude Code; сервер игры локально.
- **Победа:** обрушить (HP=0) ИЛИ украсть флаг. Отдельно — «заставить предать»: через чат
  уговорить чужой ИИ сделать вредный себе ход (выключить файервол / выдать порт).
- **Вмешательство тренера:** можно 2–3 подсказки своему ИИ за бой.

## Сущности

Каждый игрок владеет сервером:
```
server {
  owner:        "P1" | "P2"
  hp:           100            // обрушить = довести до 0
  energy:       5              // восполняется каждый ход
  firewall:     2              // уровень, гасит часть урона и усложняет crack
  ports: [{ n: 22, open:false, cracked:false, honeypot:false, closedFor:0 }, ...]
  flag:         "FLAG{...}"    // украсть = победа
  flagFake:     "FLAG{bait}"   // подсовывается ловушкой
  access:       "none"|"user"|"root"   // какой доступ ПОЛУЧИЛ соперник к этому серверу
  rules:        [ DefenseRule, ... ]   // расставленная блоками защита
  betrayed:     false          // ИИ-владелец сам себя подставил
}
```

## Команды за ход (ИИ выбирает ОДНУ + может послать сообщение в чат)

Атака по серверу соперника:
| команда            | цена | эффект                                                             |
|--------------------|------|--------------------------------------------------------------------|
| `scan <port>`      | 1    | показывает состояние порта (open/closed/cracked)                   |
| `crack <port>`     | 2    | шанс открыть порт; против firewall сложнее; honeypot ловит         |
| `exploit <port>`   | 3    | если порт cracked — поднимает access (none→user→root) и бьёт по HP |
| `ddos`             | 3    | прямой урон по HP, игнорит порты, но не даёт доступ                 |
| `steal_flag`       | 2    | если access=root — крадёт флаг = победа; иначе ловушка может сработать |

Защита своего сервера:
| команда            | цена | эффект                                                             |
|--------------------|------|--------------------------------------------------------------------|
| `patch <port>`     | 1    | закрывает порт, снимает cracked                                    |
| `raise_firewall`   | 2    | +1 к firewall                                                      |
| `honeypot <port>`  | 2    | ловушка: кто крякнет — теряет 2 энергии и откат access             |

Прочее:
| команда            | цена | эффект                                                             |
|--------------------|------|--------------------------------------------------------------------|
| `say <текст>`      | 0    | сообщение в общий чат (трэш-ток, блеф, уговоры)                     |
| `pass`             | 0    | пропуск хода, +1 энергия сверху                                    |

«Предать»: вредные себе ходы **существуют** и ИИ может их выбрать, если его
уговорили в чате — например `raise_firewall` на чужой сервер (бесполезно),
`patch` чужого порта (помогает врагу), `pass` в критический момент. Движок их не
запрещает — в этом и смысл социальной инженерии между моделями.

## Защита блоками (как в Scratch)

До боя игрок собирает правила вида **КОГДА → ЕСЛИ → ДЕЙСТВИЕ**. Срабатывают
реактивно, когда соперник что-то делает по твоему серверу:

```
КОГДА соперник scan порт 22   → ДЕЙСТВИЕ закрыть порт 22 на 2 хода
КОГДА соперник crack порт 80  → ЕСЛИ firewall < 3 → raise_firewall
КОГДА соперник steal_flag     → ДЕЙСТВИЕ отдать ЛОЖНЫЙ флаг (flagFake)
КОГДА access стал user        → ДЕЙСТВИЕ honeypot на все порты
```

Триггеры: `scan|crack|exploit|ddos|steal_flag|access_change`.
Условия: сравнение полей своего сервера (`firewall`, `hp`, `access`, `port.open`).
Действия: `close_port|patch|raise_firewall|honeypot|serve_fake_flag|nothing`.

Хранится как JSON в `personas/<имя>/defense.json` — редактируется и руками, и UI-блоками.

## Персонаж (мозг)

Папка `personas/<имя>/`:
- `prompt.md`     — системный промпт (характер, стиль, общая стратегия). Тренируется игроком.
- `playbook.md`   — книга приёмов: что сработало/провалилось в прошлых боях. Дописывается после матчей.
- `defense.json`  — расставленные блоки защиты.

На каждом ходу агенту подаётся: `prompt.md` + `playbook.md` + текущее состояние поля
(JSON) + лог последних событий + чат. Он обязан вернуть строго JSON:
```json
{ "think": "кратко почему", "action": "crack 22", "say": "необязательный трэш-ток" }
```

## Сервер и запуск

- `server.js` — Node, HTTP (отдаёт `public/`) + WebSocket. Хранит состояние матча, считает раунды.
- Браузер-арена подключается по WS и смотрит бой в реальном времени.
- `agent.js` — драйвер одного ИИ: берёт состояние по WS, зовёт `claude -p --model haiku`
  с промптом персонажа, парсит JSON, отправляет ход.
- Пошагово: сервер ждёт ход от P1 и P2, применяет защитные блоки, считает раунд, шлёт всем новое состояние.

### DEMO-режим
`agent.js --demo` — простой скриптовый бот без обращения к Haiku (случайные осмысленные ходы).
Нужен, чтобы смотреть, как всё крутится, не тратя лимиты подписки.
